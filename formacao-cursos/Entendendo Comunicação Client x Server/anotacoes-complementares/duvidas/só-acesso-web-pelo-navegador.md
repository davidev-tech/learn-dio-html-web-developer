# Só consigo acessar a Web pelo navegador?

## Dúvida
Fiquei confuso se a Web só pode ser acessada por meio de um navegador.

## Resposta

**Não.** Qualquer programa que fale HTTP/HTTPS pode acessar a Web.

- Para **visualizar** uma página como usuário comum → normalmente navegador (ou WebView, ver [[onde-o-html-roda]]).
- Para **acessar dados e serviços** → qualquer cliente HTTP serve, ver [[clientes-http]].

## Detalhe importante

O navegador é um **cliente** da Web. A Web é o conjunto de recursos e protocolos — ver [[web-vs-internet]]. Confundir os dois é o que gera essa dúvida.
