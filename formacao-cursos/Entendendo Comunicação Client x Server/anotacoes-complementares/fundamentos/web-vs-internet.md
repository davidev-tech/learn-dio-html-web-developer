# Web vs Internet

## Contexto
Confusão comum no início do curso: tratar "Web" e "Internet" como sinônimos.

## Conteúdo

- **Internet**: infraestrutura de rede que conecta dispositivos.
- **Web**: serviço que roda sobre a Internet, baseado em HTTP/HTTPS, URLs, HTML etc.

A Web é um dos vários serviços que usam a Internet (assim como e-mail, FTP, DNS, SSH...). Ver também: [[anotacoes-complementares/fundamentos/navegadores]].
