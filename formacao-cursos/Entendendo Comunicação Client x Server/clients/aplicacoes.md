# Aplicações

## Ciclo cliente ↔ servidor

Client → Web (via Internet) → Server → Banco de Dados  
↓  
Client ← Web (via Internet) ← Server ← Banco de Dados


- O cliente faz uma requisição pela internet.
- O servidor processa, consulta o banco de dados e devolve a resposta.
- O processo inverso traz os dados de volta até o cliente.

## O que é uma aplicação Web

- Solução criada que usa a **internet como meio de comunicação** entre Client e Server.
- **Não exige instalação** para ser usada.
- Consequência importante:
  - Se a aplicação **precisa ser instalada**, ela **deixa de ser Web** e passa a ser **aplicativo**.

## Formatos de aplicação

- **Só Web**
- **Só aplicativo**
- **Ambos os ecossistemas** (web + app)

## Ecossistema Web vs Ecossistema de Aplicativos

- Cada um tem **conjunto próprio de tecnologias de produção**.
- Cada um tem **preocupações diferentes** (instalação, distribuição, atualização, desempenho, etc.).
- Não é só "a mesma coisa em telas diferentes" — são mundos com ferramentas e decisões próprias.
