# Dispositivos Móveis

## 1. O que são

- Dispositivos que você consegue utilizar em vários lugares.
- Mobilidade é a característica central: o uso não fica preso a um lugar fixo.

## 2. Por que importa no desenvolvimento

- O crescimento dessas tecnologias **não é o futuro, é uma realidade**.
- Por isso, é preciso levar em consideração a **compatibilidade** deles no desenvolvimento.
