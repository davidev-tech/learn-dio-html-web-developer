hospedagem: É você colocar o seus arquivos da aplicação em um servidor na internet.

Podemos ter o nosso própio, servidor instalando, ou contratar um servidor de hospedagem. Variando os valores de acordo com empresa e serviços.

requisições em serviço: HTTP é uma requisição na qual os dados são mantidos da forma que foram enviados, sem nenhuma camada de segurança, deixando senhas e dados expostos. Por padrão roda na porta 80. http://
O HTTPS é uma conexão segura , na qual os dados são criptografados. Aumentando a segurança, dificultando interceptação dos dados. Por padrão roda na porta 443. https://
**HTTPS** usa protocolos de segurança como SSL/TLS para embaralhar os dados, impedindo que terceiros leiam informações interceptadas. 
**Certificado Digital:** O **HTTP** não precisa de certificado. O **HTTPS** exige um certificado digital válido para validar a identidade do servidor.

Um servidor pode ser um servidor de mais de um tipo.

o nome do site é um registro que pode acabar tendo vários com o mesmo nome.
O que acontece se os nomes forem iguais?

- **Confusão dos usuários:** Se o seu site tiver o mesmo nome de um concorrente famoso, os usuários podem se confundir ao buscar pelo nome no Google.

- **Problemas legais:** Se o nome do site for uma marca registrada (ex: "Nike" ou "Netflix"), o proprietário legal da marca pode acionar a justiça para exigir que você altere o nome do seu site por violação de propriedade intelectual, mesmo que o seu domínio DNS seja diferente.
